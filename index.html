what i built

เว็บไซต์นี้คือ learning portfolio ที่สร้างขึ้นด้วยจุดประสงค์ในการฝึกใช้และศึกษาวิธีการใช้HtmlและCSSในการจัดองค์ประกอบของwebsite โดยมีรายละเอียดดังนี้

  • about me ( ส่วนแนะนำตัว )
  • what i built ( ส่วนแนะนำwebsite )
  • how i built it ( ส่วนนำเสนอกระบวนการสร้าง )
  • reflection ( ส่วนสะท้อนการเรียนรู้ )
  • footer (ส่วนสุดท้ายที่เชื่อมลิ้งค์และช่องทางการติดต่อ)

ในขณะที่เปิดเว็บไซต์จากเครื่องของตนเอง

  • มี Client ที่เกิดขึ้นจากการเปิดเว็บเบราว์เซอร์ ที่ใช้อ่าน
    และแสดง HTMLและCSS จากไฟล์ที่ถูกเก็บไว้ในเครื่องของตนเอง
  • แต่ยังไม่มี Server เนื่องจากเว็บไซต์ถูกโหลดจากไฟล์ที่อยู่ในเครื่อง
    ของตนเองโดยตรง โดยไม่ได้ส่งคำขอ(request)ไปยัง Web Server

How i built it

กระบวนการสร้างเว็บไซต์

เริ่มต้นจากการวางโครงสร้างหน้าเว็บด้วย HTML และสร้างไฟล์ External CSS แยกออกมา (เช่น style.css) เพื่อเชื่อม ระหว่างทั้ง2ไฟล์
โดยจะใช้ HTML เป็นโครงสร้างสำหรับการวางเนื้อหา หัวข้อ รวมถึงสื่อต่างๆเป็นอันดับแรก จากนั้นจึงใช้ CSS สำหรับตกแต่งเว็บไซต์ เช่น สีพื้นหลัง สีตัวอักษร ขนาดรูปภาพ ระยะห่าง หรือการจัดตำแหน่งขององค์ประกอบเป็นลำดับถัดมา

เครื่องมือและแหล่งข้อมูลประกอบการเรียนรู้

ใช้VS code เป็นเครื่องมือหลักในการเขียนโค้ด จากนั้นศึกษาความรู้เพิ่มเติมผ่าน website W3school youtube และgoogle

Reflection

ปัญหาหรือความท้าทายที่พบและวิธีรับมือ

ความท้าทาย: เนื่องจากเป็นผู้ที่เพิ่งเรียนรู้และศึกษาการcodingจึงยังต้องทำความคุ้นเคยเพิ่มเติมอีกมาก วิธีรับมือ: ทดลองแก้ไขโค้ดทีละส่วนและศึกษาความหมายของคำสั่งแต่ละคำสั่ง รวมถึงศึกษาความรู้ด้วยตัวเองผ่านอินเตอร์เน็ต

สิ่งที่เข้าใจเกี่ยวกับการพัฒนาเว็บไซต์มากขึ้น

เข้าใจหน้าที่ของ HTML ซึ่งมีหน้าที่หลักในการสร้างโครงสร้างและเนื้อหาของเว็บไซต์ ส่วน CSS ใช้ในการตกแต่งและจัดรูปแบบ รวมถึงสร้างความเข้าใจว่าเว็บไซต์เกิดจากการทำงานร่วมกันขององค์ประกอบหลายอย่าง เช่นCSSและHTML

สิ่งที่อยากพัฒนาหรือปรับปรุงในอนาคต

อยากปรับปรุงให้โครงสร้างhtmlเป็นระเบียบมากขึ้น และสามารถเพิ่มลูกเล่นโต้ตอบให้เว็บไซต์มีความน่าสนใจรวมถึงสามารถใช้ได้ง่ายขึ้น
